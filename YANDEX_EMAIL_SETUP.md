# 📧 Настройка Яндекс почты для отправки писем

## 🎯 Цель: 
Настроить backend для отправки писем с вашей Яндекс почты на **pasha007@eko-bike.ru**

---

## 📝 Шаг 1: Включите IMAP в Яндекс почте

1. Откройте: https://mail.yandex.ru/
2. Нажмите **⚙️ (настройки)** → **Все настройки**
3. Перейдите в раздел **"Почтовые программы"**
4. Найдите опцию **"С сервера imap.yandex.ru по протоколу IMAP"**
5. **Включите** эту опцию
6. Нажмите **"Сохранить"**

---

## 🔑 Шаг 2: Создайте пароль приложения (Рекомендуется)

### Если у вас включена двухфакторная аутентификация:

1. Откройте: https://id.yandex.ru/security/app-passwords
2. Нажмите **"Создать новый пароль"**
3. Выберите **"Почта"**
4. Введите название: `EKO-BIKE Server`
5. Нажмите **"Создать"**
6. **Скопируйте пароль** (его можно посмотреть только один раз!)

### Если НЕТ двухфакторной аутентификации:

Используйте обычный пароль от Яндекс почты (но лучше включить 2FA и использовать пароль приложения)

---

## ⚙️ Шаг 3: Создайте файл `.env` в папке `server`

Создайте файл `server/.env` со следующим содержимым:

```env
# Server Configuration
PORT=5000

# Yandex Email Configuration
EMAIL_HOST=smtp.yandex.ru
EMAIL_PORT=465
EMAIL_USER=ваш_email@yandex.ru
EMAIL_PASS=ваш_пароль_или_пароль_приложения

# Recipient Email (куда отправлять письма)
RECIPIENT_EMAIL=pasha007@eko-bike.ru

# Frontend URL
FRONTEND_URL=http://localhost:3000
```

### Пример заполнения:

```env
PORT=5000
EMAIL_HOST=smtp.yandex.ru
EMAIL_PORT=465

EMAIL_PASS=abcd1234efgh5678

```

## ❓ Частые проблемы с Яндекс

### 1. Ошибка: "Invalid login"

**Причины:**
- Неправильный email или пароль
- IMAP не включен в настройках
- Пароль приложения неверный

**Решение:**
1. Проверьте email: `EMAIL_USER=ваш_email@yandex.ru`
2. Включите IMAP: https://mail.yandex.ru/ → Настройки → Почтовые программы
3. Создайте новый пароль приложения

---

### 2. Ошибка: "Connection timeout"

**Причины:**
- Неправильный хост или порт
- Файрвол блокирует соединение

**Решение:**
1. Убедитесь: `EMAIL_HOST=smtp.yandex.ru`
2. Убедитесь: `EMAIL_PORT=465`
3. Попробуйте отключить антивирус/файрвол временно

---

### 3. Ошибка: "Self signed certificate"

**Решение:**
Это нормально! В `server/config/emailConfig.js` уже настроено:
```javascript
tls: {
  rejectUnauthorized: false
}
```

---

### 4. Письма не приходят на pasha007@eko-bike.ru

**Проверьте:**
1. ✅ Папку "Спам" в почте pasha007@eko-bike.ru
2. ✅ Логи backend сервера (должно быть `✅ Письмо отправлено`)
3. ✅ Правильность `RECIPIENT_EMAIL=pasha007@eko-bike.ru`
4. ✅ Что письмо уходит с вашего Яндекс (проверьте Отправленные)
