## 📝 Пошаговый план:

### ✅ ШАГ 1: Подготовка (на компьютере)

```bash
# 1. Убедитесь что всё работает локально
npm run server     # Терминал 1
npm start          # Терминал 2

# 2. Протестируйте формы
# 3. Создайте production build
npm run build
```

Должна появиться папка `build`

---

### ✅ ШАГ 2: Deploy Backend

#### Render.com (БЕСПЛАТНО):

1. Регистрация: https://render.com
2. New + → Web Service
3. Настройки:
   ```
   Root Directory: server
   Build Command: npm install
   Start Command: npm start
   ```
4. Добавить переменные:
   ```
   EMAIL_HOST=smtp.yandex.ru
   EMAIL_PORT=465
   EMAIL_USER=ваш_email@yandex.ru
   EMAIL_PASS=ваш_пароль
   RECIPIENT_EMAIL=pasha007@eko-bike.ru
   ```
5. Deploy → Скопировать URL

**Проверка**: Откройте `https://ваш-backend.onrender.com/api/health`

---

### ✅ ШАГ 3: Deploy Frontend

#### Netlify (БЕСПЛАТНО):

1. Регистрация: https://netlify.com
2. Sites → Add new site → Deploy manually
3. Перетащить папку `build`
4. Добавить переменную:
   ```
   REACT_APP_API_URL=https://ваш-backend.onrender.com/api
   ```
5. Redeploy

**Проверка**: Откройте `https://ваш-сайт.netlify.app`

---

### ✅ ШАГ 4: Связать Frontend и Backend

#### В Render (Backend):
Добавить переменную:
```
FRONTEND_URL=https://ваш-сайт.netlify.app
```

#### В Netlify (Frontend):
Уже добавили `REACT_APP_API_URL` ✅

Оба сервиса redeploy автоматически.

## 🆘 Если что-то не работает:

### 1. Backend не отвечает:
- Проверьте статус на Render: должен быть "Active"
- Посмотрите логи: Logs в Render
- Проверьте все переменные окружения

### 2. Формы не отправляются:
- Откройте консоль браузера (F12)
- Проверьте `REACT_APP_API_URL` в Netlify
- Проверьте `FRONTEND_URL` в Render
- Проверьте CORS настройки

### 3. Email не приходят:
- Проверьте папку "Спам"
- Проверьте `EMAIL_USER` и `EMAIL_PASS`
- Попробуйте отправить тестовое письмо из backend

### 4. Домен не работает:
- Подождите 1-24 часа для DNS
- Проверьте правильность DNS записей
- Проверьте что домен активен
