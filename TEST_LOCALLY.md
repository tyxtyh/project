# 🧪 Тестирование работы локально

## Шаг 1: Установите зависимости

```bash
# Backend
cd server
npm install
cd ..

# Frontend (если еще не установлены)
npm install
```

---

## Шаг 2: Настройте email для тестов

### Создайте файл `server/.env`:

```env
PORT=5000
EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_USER=your_email@gmail.com
EMAIL_PASS=your_app_password
RECIPIENT_EMAIL=pasha007@eko-bike.ru
FRONTEND_URL=http://localhost:3000
```

### Получите пароль приложения Gmail:

1. Откройте: https://myaccount.google.com/security
2. Включите **двухфакторную аутентификацию** (если еще не включена)
3. Откройте: https://myaccount.google.com/apppasswords
4. Выберите "Почта" → "Компьютер Windows" → "Создать"
5. Скопируйте пароль (16 символов без пробелов)
6. Вставьте в `.env` в поле `EMAIL_PASS`

**💡 Совет для тестов:** Можете временно указать свой email в `RECIPIENT_EMAIL` чтобы проверять письма в своей почте.

---

## Шаг 3: Запустите backend сервер

Откройте **первый терминал**:

```bash
npm run server
```

Или:

```bash
cd server
npm start
```

### ✅ Успешный запуск выглядит так:

```
🚀 EKO-BIKE Server запущен!
📧 Email сервер работает на порту 5000
🌐 Frontend URL: http://localhost:3000
📬 Письма отправляются на: pasha007@eko-bike.ru
✅ Email сервер готов к отправке писем

Для остановки нажмите Ctrl+C
```

### ❌ Если видите ошибки:

**Ошибка: "Invalid login"**
- Проверьте `EMAIL_USER` и `EMAIL_PASS` в `.env`
- Убедитесь что используете пароль приложения, не обычный пароль
- Включите двухфакторную аутентификацию

**Ошибка: "ECONNREFUSED"**
- Проверьте интернет соединение
- Попробуйте порт 465 вместо 587

## Шаг 4: Запустите frontend

Откройте **второй терминал** (не закрывая первый!):

```bash

```

Браузер автоматически откроется на http://localhost:3000

## Шаг 5: Протестируйте формы

### Тест 1: Форма "Заказать звонок"

1. На сайте нажмите любую кнопку **"Заказать звонок"**
2. Заполните форму:
   - Имя: Тест
   - Телефон: +7 999 123-45-67
   - Email: test@example.com
   - Сообщение: Тестовое сообщение
3. Нажмите **"Отправить"**

**Что должно произойти:**
- Кнопка изменится на "Отправка..."
- Появится сообщение "Спасибо! Ваша заявка отправлена..."
- Модалка закроется
- В терминале backend увидите: `✅ Письмо отправлено: <message-id>`
- Письмо придет на `pasha007@eko-bike.ru` (или на ваш email если изменили)

---

### Тест 2: Форма в контактах

1. Прокрутите вниз до секции **"Оставьте заявку на консультацию"**
2. Заполните форму
3. Нажмите **"Отправить заявку"**

**Проверьте:**
- Форма очистилась после отправки
- Появилось сообщение об успехе
- В backend логах: `✅ Письмо отправлено`

---

### Тест 3: Форма заказа товара

1. Откройте любой товар в каталоге
2. Нажмите **"Подробнее"**
3. В модалке нажмите **"Купить"**
4. Заполните форму заказа:
   - ФИО
   - Телефон
   - Email
   - Адрес доставки
   - Выберите способ оплаты
   - (Опционально) Выберите доп. оборудование
5. Нажмите **"Оформить заказ"**

**Проверьте:**
- Письмо содержит информацию о товаре
- Указана итоговая стоимость
- Перечислено выбранное доп. оборудование

## 🔍 Проверка через консоль браузера

Откройте консоль разработчика (F12) и проверьте:

### ✅ Успешная отправка:

```
Данные успешно отправлены: {success: true, message: "Заявка успешно отправлена", ...}
```

### ❌ Ошибка:

```
Ошибка отправки: Failed to fetch
```

**Причина:** Backend не запущен или неправильный URL

**Решение:** 
1. Проверьте что backend запущен: http://localhost:5000/api/health
2. Должен вернуть: `{"status":"OK","message":"EKO-BIKE Server is running"}`

## ❓ Частые проблемы

### 1. Backend не запускается

**Ошибка:** `Cannot find module 'express'`

**Решение:**
```bash
cd server
npm install
```

---

### 2. Frontend показывает ошибку "Failed to fetch"

**Причины:**
- Backend не запущен
- Неправильный порт
- CORS проблемы

**Решение:**
1. Проверьте что backend запущен: http://localhost:5000/api/health
2. Убедитесь что в `server/.env` указан `FRONTEND_URL=http://localhost:3000`
3. Перезапустите оба сервера

---

### 3. Письма не приходят

**Проверьте:**
1. ✅ Папку "Спам"
2. ✅ Логи backend сервера (должно быть `✅ Письмо отправлено`)
3. ✅ Правильность `EMAIL_USER` и `EMAIL_PASS` в `.env`
4. ✅ Используется пароль приложения Gmail, не обычный пароль

**Тестовая отправка:**
```bash
# В папке server
node -e "require('./services/emailService').sendCallbackRequest({name:'Test',phone:'123',email:'test@test.com'}).then(console.log)"
```

---

### 4. Ошибка "Invalid login"

**Решение:**
1. Откройте https://myaccount.google.com/apppasswords
2. Создайте НОВЫЙ пароль приложения
3. Скопируйте его БЕЗ ПРОБЕЛОВ
4. Вставьте в `server/.env` в `EMAIL_PASS`
5. Перезапустите backend
